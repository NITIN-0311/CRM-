
Commands 

1.Setup

git config --global user.name "<name>"
git config --global user.email "<email>"

2.Initialize 

git init
git clone <url>


3.Basic Commands

git status
git add <filename>/.  -> create snapshot
git commit -m "message"  -> store snapshot
git log


4.Working with Origin

note -  origin(convention) is just a user define name for remote repo

a.git remote add origin <url> -> connect remote repo
b.git remote -v   -> check if repo connected
c.git remote remove origin   
d.git push <repo name> <branch name>
